# Vitale — Projeto demonstrativo

Projeto fictício criado pela **JT Sites** para demonstrar uma presença digital clara, acolhedora e organizada para clínicas e consultórios.

## Conceito
- paleta clara em sálvia e creme
- hierarquia de informação voltada a confiança e orientação
- atendimentos e jornada apresentados como exemplos
- fluxo visual de contato sem envio real de dados
- layout responsivo

> Vitale é uma marca fictícia. Não representa clínica, profissional, especialidade ou serviço de saúde real.

## GitHub Pages
